# Response to Reviewer 1 Comment 2

We thank the reviewer for requesting clarification of preprocessing, model configuration and PLS component selection. We distinguish the preprocessing reported in the originating study from the operations implemented in the current classification evaluation.

The originating study, Dev et al. [13], describes exclusion of spectra when the PMMA-associated intensity at 1735 cm⁻¹ exceeded half of the amide I intensity at 1660 cm⁻¹. It also describes Savitzky–Golay smoothing and second-derivative processing, followed by outlier identification in peak-ratio datasets using limits of Q1 − 1.5×IQR and Q3 + 1.5×IQR. These are published source-study procedures. We cannot infer their complete application to the exact workbook from the presence of modeling code alone.

The current evaluation begins with the prepared raw, second-derivative and peak-ratio worksheets. It performs no additional PMMA rejection, IQR-based observation removal, smoothing or derivative generation. For each representation, 250 observations per animal are sampled without replacement using seed 42 before cross-validation. Sampling uses no feature-based ranking or fitted selection criterion. All evaluated models use the same selected observations within a representation, and the selected source rows are exported. This does not establish physical spectrum matching between different representations.

Classification is evaluated using outer leave-one-animal-out cross-validation. Each fold trains on 11 animals (2,750 observations) and evaluates the remaining animal (250 observations). StandardScaler estimates feature means and standard deviations exclusively from the training observations and applies that transformation to the held-out observations. This procedure is used for SVM, KNN, logistic regression, random forest, XGBoost and PLS-DA.

The classifiers use fixed configurations, and no automated classifier hyperparameter search is performed in the implemented evaluation workflow. Complete estimator parameters, fitted XGBoost booster configurations and exact software versions are provided with the reanalysis. The original implemented PLS evaluation fixes the number of latent variables at three; it does not select that count through inner cross-validation.

To evaluate component choice, we performed an additional nested, animal-grouped PLS analysis. Components 1–5 were compared using inner leave-one-animal-out cross-validation restricted to each outer training set. Each inner fold fits a fresh scaler using its training animals only. The count maximizing mean inner-animal accuracy is selected, choosing the smallest count for a tie within absolute tolerance 1e-12. A fresh scaler and selected PLS model are then fitted on all outer training animals and evaluated on the outer-test animal. The fixed-three-component results remain a separate reference. Raw fingerprint accuracy is 86.97% with nested selection and 86.63% with fixed-three PLS. These additional results do not retrospectively establish the historical reason for the original component count or a globally optimal count.

The available workbook and repository do not preserve the original exclusion log, the grouping used to estimate IQR quartiles, the exact derivative settings used to create the workbook, or whether the source-study ratio exclusions affected the classification observations. Consequently, we cannot establish the absence of information leakage during earlier data-dependent preparation. We explicitly limit the current performance estimates to the supplied prepared dataset. Training-only scaling and nested selection establish separation for the validation-stage operations and do not reconstruct upstream exclusions.

The accompanying Methods text and supplementary output report the sampling sequence, feature definitions, fold-specific scaling, fixed classifier settings, component-selection records, per-animal performance and computational environment. The evaluated collagen window is 1300–1700 cm⁻¹; supplied ratio headers are retained verbatim. Archived and newly generated results are identified separately, including the small random forest reproduction difference.
